# Cezéc | Casa Espiritual Zé Corisco

Site institucional e de apresentação da Casa Espiritual Zé Corisco, desenvolvido em HTML, CSS e JavaScript para funcionar como um projeto estático e ser publicado facilmente no GitHub Pages.

A proposta do site é transmitir a identidade da casa, apresentar os serviços e atendimentos espirituais, oferecer contato rápido pelo WhatsApp e manter uma presença digital moderna e profissional.

## Objetivo do projeto

- Apresentar a Casa Espiritual Zé Corisco
- Exibir serviços e atendimentos
- Dar destaque à espiritualidade, acolhimento e fé
- Conectar visitantes ao WhatsApp para agendamento
- Publicar de forma simples e estática sem backend

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript vanilla
- API do GitHub para exibição de projetos
- GitHub Pages para hospedagem estática

## Páginas principais

- `index.html` — página inicial
- `inicio.html` — entrada em português

- `todos_os_serviços.html` — catálogo completo
- `desenvolvimento.html` — página complementar de projetos/soluções

## Como rodar localmente

No terminal, na pasta do projeto:

```bash
python -m http.server 8000
```

Depois abra no navegador:

```text
http://localhost:8000/
```

## Como publicar no GitHub Pages

1. Faça o push do projeto para um repositório GitHub.
2. Acesse as configurações do repositório.
3. Vá em "Pages".
4. Selecione a branch correta como origem.
5. Salve e aguarde a publicação.
6. O site ficará disponível em uma URL pública.
